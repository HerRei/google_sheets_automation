Overview

Automating repetitive data entry

This project demonstrates how a lightweight Flask app can collect structured input and send it directly to Google Sheets through the Google Sheets API. The primary goal is to save time when similar details need to be entered repeatedly, while keeping the implementation small, testable, and easy to configure.

Features

Focused implementation details

Flask-based input flow

Provides a compact web interface for collecting structured records.

Google Sheets API integration

Writes validated entries to a configured spreadsheet.

Structured package layout

Keeps application code organized for local development and testing.

User Editable Configuration

Sheet ids, OAuth files, labels, and record options are edited locally.

pytest test coverage

Includes automated checks for the core application behavior.

Time-Saving Design

Pre-populated buttons for dates, records, and record types reduce typing.
